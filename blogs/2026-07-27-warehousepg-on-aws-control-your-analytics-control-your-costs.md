WarehousePG is a massively parallel processing (MPP) database originating from the open source Greenplum database. Sadly, Greenplum database is no longer open source, but EnterpriseDB is now the steward of this Apache-licensed open source project. This blog post covers some of the ways you can deploy WarehousePG in AWS.
